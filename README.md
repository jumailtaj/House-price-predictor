🏡 **House Price Prediction Using Machine Learning | Internship Project**

I'm happy to share one of my Machine Learning projects: **Indian House Price Predictor**, developed during my one-month internship from **7 August to 7 September**.

The objective of this project was to build a beginner-level Machine Learning model that predicts house prices based on property details.

🔹 **Technologies Used:**
- Python
- Pandas & NumPy
- Matplotlib
- Scikit-learn
- Google Colab
- Machine Learning (Regression)

🔹 **What I implemented:**
- Dataset loading and preprocessing
- Handling missing values and cleaning data
- Exploratory Data Analysis (EDA)
- Feature selection and encoding
- Linear Regression
- Random Forest Regression
- Model evaluation using MAE, RMSE and R² Score
- Predicting house prices based on user inputs

🔹 **Why did I choose a GitHub repository for the dataset instead of downloading it from dataset platforms?**

One interesting decision in this project was choosing a GitHub-hosted dataset.

My reasons were:

1. **Direct accessibility:** I could load the CSV directly into Google Colab using Pandas without manually downloading and uploading the file.
2. **Reproducibility:** Anyone accessing the repository can use the same dataset and reproduce the project.
3. **Transparency:** The dataset source is accessible, making it easier to track where the data came from.
4. **Convenience:** It simplifies the workflow and makes sharing the project easier.

This helped me understand that choosing a dataset source is also an important part of building a practical Machine Learning project.

🔹 **Key Learning:**

This project helped me understand the basic Machine Learning workflow, from collecting and cleaning data to training, evaluating and making predictions using regression models.
